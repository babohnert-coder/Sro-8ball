# Unsupported Answer Forms

The current authored response bank has no dedicated quantity/count lane.

Quantity-shaped prompts such as `how many wins will JohnWestGamer get?` are recognized as prediction-shaped so named-person lore does not hijack the answer, but the runtime falls back to the existing direct prediction pool. This task did not add new authored dialogue, response fragments, template assembly, or a new quantity route.

Future support would require editorially approved quantity/count responses before adding a first-class quantity answer shape.
